One emoji for a dream vacation — a wordless postcard. The pick is Mount Fuji: one snow-capped peak, one place on Earth, recognised in every country. A mountain is on the judge's own list of dream-vacation landings, and Fuji is the most photographed one — specific where the beach is generic, a postcard you can see before reading a word.

> 🗻

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is exactly 1 emoji (1 code point, 4 bytes UTF-8), within the 1–8 character gate.
